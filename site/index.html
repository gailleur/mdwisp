Markdown. Nothing else.

A minimalist Markdown viewer and editor that protects your privacy.
Open source, for macOS, Linux and Windows.

Download All releases

Free. Apache License 2.0.

Secure

Documents are sanitised before rendering, and the window runs under a strict Content Security Policy. A document cannot run code.

Private

The app makes no network requests on its own. No telemetry, no CDNs, no automatic update checks: Help ▸ Check for Updates connects only when you choose it, and compares versions on your machine.

Light

A native shell on the system webview, not an embedded browser. Opens in an instant and stays out of the way.

  • Reading view, WYSIWYG editing and a source view, one keystroke apart.
  • GitHub-flavoured Markdown, tables, task lists, footnotes, maths and Mermaid diagrams.
  • Tabs, an outline sidebar, find and replace, and a block picker.
  • Follows the file on disk and warns before anything is overwritten.
  • Prints and exports to PDF without leaving the app.
  • Offers to become the default app for .md, and never changes it without asking.

Download

Installers are built and published on GitHub for every release. Each release carries a SHA256SUMS file; verify a download with sha256sum -c SHA256SUMS. Once installed, Help ▸ Check for Updates in the app fetches and installs newer releases when you ask; nothing checks on its own.

macOS Disk image Apple silicon Signed and notarized by Apple.
Windows Installer · MSI x64 Not yet code-signed: choose More info, then Run anyway.
Linux deb · rpm · AppImage x86_64 The deb and rpm register .md with the desktop; the AppImage cannot.
