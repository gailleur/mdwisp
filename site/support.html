Getting started

Open a Markdown file with File ▸ Open, drag it onto the window, or double-click it in your file manager once mdwisp is your default Markdown app. The first launch offers to make it the default; File ▸ Use mdwisp for .md Files does the same later.

Every document has three views, one keystroke apart: Reading (⌘1), Editor (⌘2) for visual editing, and Source (⌘3) for the raw text. On Linux and Windows use Ctrl in place of ⌘.

The full list of shortcuts and editing commands is in the app under Help ▸ mdwisp Help (⌘/). It works offline, like everything else.

Common questions

Images beside my document do not show (Mac App Store version).
The App Store version runs in Apple's sandbox, which lets it read only the files you open. When a document uses images from its folder, a banner offers to grant that folder; choose allow and pick the folder. The grant is remembered. The version downloaded from mdwisp.com does not need this.
Images from the web do not show.
They are off by default so the app never contacts anyone without asking. Turn them on per session with View ▸ Remote Images.
The file changed while I was editing.
mdwisp follows the file on disk. If you had unsaved edits, a banner lets you keep yours or take the disk copy. Nothing is overwritten without that choice.
Where are my settings?
On your own machine only: window position, theme, zoom and the outline state. There is no account and nothing to sync.
Does it update itself?
No. The app never checks for updates. New versions are announced on the releases page, and the Mac App Store updates its copy the way it updates any app.

Reporting a problem

Please open an issue on GitHub with your platform, the app version from the About box, and what you expected to happen. A small Markdown file that reproduces the problem helps most. Security concerns go to the address in the repository's SECURITY.md.
