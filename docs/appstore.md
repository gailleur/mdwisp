## Promotional text

A minimalist Markdown viewer and editor that never touches the network.

## Description

mdwisp opens Markdown files instantly, renders them cleanly, and lets you
edit them in place. It has no account, no cloud, no analytics and no update
checks. It never makes a network request on its own.

THREE VIEWS, ONE KEYSTROKE APART
• Reading: a quiet, well-typeset page.
• Editor: visual editing with headings, lists, tables, links and code
  that stay Markdown underneath.
• Source: the raw text with syntax colouring, for when you want control.

RENDERS WHAT YOU WRITE
GitHub-flavoured Markdown, tables, task lists, footnotes, code blocks with
one-click copy, maths (LaTeX) and Mermaid diagrams. Everything renders
offline, from the app bundle.

STAYS OUT OF THE WAY
Tabs, an outline sidebar, find and replace, a block picker, reading time,
light and dark themes, zoom. The window remembers where you left it.

SAFE WITH YOUR FILES
mdwisp follows the file on disk and reloads when it changes elsewhere. If
you have unsaved edits, it asks before anything is overwritten. Saves are
plain Markdown; there is no proprietary format.

PRINT AND EXPORT
Print, or export the reading view to PDF, without leaving the app.

PRIVATE BY CONSTRUCTION
Documents are sanitised before rendering, so a document cannot run code.
Images from the web are off until you turn them on. The app contains no
telemetry of any kind, and the full source is public under the Apache
License 2.0 at github.com/gailleur/mdwisp. The privacy policy fits in one
paragraph because there is nothing to collect.

PURPOSE AND AUDIENCE
mdwisp is a viewer and editor for Markdown (.md) files, the plain-text
format used for README files, notes and documentation. It is for
developers, writers and anyone who keeps notes in Markdown and wants a
fast, private app that opens the file, renders it well and edits it in
place without accounts, cloud sync or telemetry. The value is a document
that stays a plain file on disk and an app that makes no network request
on its own.

SETUP AND MAIN FEATURES
No sign-in, no account, no setup. Launch the app, then File ▸ Open (⌘O)
any .md file, or drag one onto the window, or use File ▸ New (⌘N) and
type. Any text file with Markdown works as a sample; a document that
exercises every feature is in the public repository:
https://github.com/gailleur/mdwisp/blob/main/samples/showcase.md
(raw file: https://raw.githubusercontent.com/gailleur/mdwisp/main/samples/showcase.md,
save it with a .md extension). Main features: three views of the same file (Reading
⌘1, Editor ⌘2, Source ⌘3), tabs, outline sidebar (⌘⌥S), find (⌘F),
light/dark theme (⌘⇧D), File ▸ Export PDF (⌘⇧E), File ▸ Print. The
Help menu (⌘/) lists every shortcut. On first launch a one-line banner
offers to make mdwisp the default app for .md files; it uses the system
consent dialog and can be dismissed. Images stored beside a document
trigger a banner asking to grant that folder (App Sandbox); choosing
"allow" opens the system folder dialog.

EXTERNAL SERVICES
None. The app uses no data providers, authentication, payments,
analytics, crash reporting or AI services. Rendering (Markdown, LaTeX
maths, Mermaid diagrams) runs entirely inside the app bundle. The only
network access is optional and user-initiated: a document that embeds an
image from a web URL loads it only after View ▸ Remote Images is
turned on. The App Store build has no update mechanism of its own;
updates come through the App Store.

REGIONAL DIFFERENCES
None. The app behaves identically in every region; it is English-only
and has no region-dependent content or features.

REGULATED INDUSTRY / PROTECTED MATERIAL
Not applicable. The app contains no third-party content; the source code
is public under the Apache License 2.0 at github.com/gailleur/mdwisp,
with third-party open-source notices included in the bundle.
